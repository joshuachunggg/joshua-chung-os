# Joshua Chung OS Portfolio

A desktop-style portfolio for Joshua Chung, focused on AI systems, finance, energy, and operations.

## Run locally

```bash
npm install
npm run dev -- -p 3001
```

For a public development preview through ngrok, run the command above and point the tunnel at port `3001`.

## Build

```bash
npm run build
```

Portfolio content lives in `src/data/resume.ts`.
